## ⚡ About Me

Security engineer focused on **red team operations** and **data protection**. I build offensive and defensive tooling to understand how systems are attacked — so they can be hardened.

- 🔬 USB / HID forensics — spotting BadUSB, Rubber Ducky and rogue devices
- 🩸 Honeypots, C2 frameworks and attack simulations for training & research
- 🛡️ Data protection, secret scanning and defensive security engineering
- 🐍 Everything in Python, living in the terminal
